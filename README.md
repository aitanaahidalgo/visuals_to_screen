# visuals_to_screen
disseny en moviment
Como punto de partida, hemos elegido la naturaleza como temática principal, con el objetivo de explorar sus formas, movimientos y transformaciones mediante la programación creativa. A partir de una búsqueda en Instagram y plataformas como Processing y The Nature of Code, hemos seleccionado tres referentes:

1. Ramificaciones y formas orgánicas
Nos interesa explorar el crecimiento de los árboles y cómo la modificación de variables como el ángulo, la longitud o la dirección de las ramas permite generar estructuras cambiantes.
https://processing.org/examples/tree.html 
https://natureofcode.com/fractals/#example-87-a-stochastic-tree

2. Crecimiento aleatorio
Este referente nos permite experimentar con movimientos y recorridos aleatorios para simular el crecimiento progresivo de raíces, creando composiciones orgánicas e impredecibles.
https://natureofcode.com/random/#example-01-a-traditional-random-walk

3. Degradados y transformación cromática
Nos interesa explorar las transiciones de color y luminosidad para representar los cambios de luz en la naturaleza, como los que se producen durante el amanecer o el atardecer.
https://processing.org/examples/radialgradient.html

La intención es combinar los tres referentes en un mismo sistema de programación, integrando el crecimiento de estructuras orgánicas, los movimientos aleatorios y las transiciones cromáticas. A partir de esta base, podremos modificar diferentes parámetros para generar tres composiciones audiovisuales distintas, manteniendo una misma identidad visual y temática.
