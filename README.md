# visuals_to_screen
disseny en moviment
En primer lugar definimos una temática la cual nos ayudaría a desarrollar las composiciones y buscar de una manera creativa que referentes elegir. A partir de diversos videos de Instagram y páginas como la de processing y the nature of Code, seleccionamos varios referentes:
El primer referente está inspirado en la naturaleza, el cual nos ayudará a incorporar elementos cambiantes que distorsionen o afecten esta. encontramos dos ejemplos: 
https://processing.org/examples/tree.html 
https://natureofcode.com/fractals/#example-87-a-stochastic-tree

El segundo referente está inspirado en las raíces y como estas crecen de manera aleatoria lentamente según pasa el tiempo:
https://natureofcode.com/random/#example-01-a-traditional-random-walk

El último referente lo elegimos por el degradado y el cambio de colores, el cual también puede dar juego para crear variables y puede transmitir el cambio de colores y la luz de la naturaleza:
https://processing.org/examples/radialgradient.html
